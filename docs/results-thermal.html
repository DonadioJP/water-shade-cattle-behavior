5 · Thermography

Thermographic images were obtained from 16 cows (4 per group: 2 Braford, 2 Jersey) at 10:00, 13:00, and 16:00h. Body temperature was calculated as (temp_mean + temp_max) / 2 following Montanholi et al. (2008). Four anatomical regions were assessed: right side (flank), left side (flank), eye, and udder. For flank analyses, the right and left flank values are averaged per animal × day × capture time, so each animal contributes one flank value per capture (not two).

All animal-level thermography models include (1 | group) + (1 | group:period) + (1 | animal_id) + (1 | day), with period as a fixed effect. Model-based results are reported as estimated marginal means (EMM) ± SE; descriptive tables report raw mean ± SD.

Thermal Environment

Shade reduced all measured thermal indices (p < 0.001; Table 2). Mean black globe temperature in the sun was 32.66 °C compared to 28.44 °C in shade — a mean difference of 4.22 °C (p < 0.001). Peak unshaded black globe temperature reached 50.7 °C, compared to 29.1 °C in shade at the same hour.

Black Globe-Humidity Index (BGHI)

In unshaded paddocks, mean BGHI was 82.25 compared to 78.02 in shade (p < 0.001). Unshaded conditions exceeded the critical threshold (BGHI > 84) in 34 out of 88 hourly observations and reached danger or critical levels (BGHI > 78) in 56 out of 88 observations. Shaded paddocks exceeded the critical threshold in 10 out of 88 observations and reached danger or critical levels (BGHI > 78) in 47 out of 88 observations, indicating that shade reduced but did not eliminate heat stress.

Radiant Thermal Load (RTL)

Mean RTL in sun was 659.2 W/m² compared to 520.4 W/m² in shade, representing a reduction of 21.1% (p < 0.001). Peak RTL in unshaded areas reached 1471.3 W/m².

Soil Surface Temperature

Mean soil surface temperature was 25.32 °C in shade, 30.23 °C in sun between trees, and 32.06 °C in full sun. Sun between trees was 4.91 °C warmer than shade (p < 0.001) and full sun was 6.74 °C warmer than shade (p < 0.001).

Body Surface Temperature

By Treatment

Flank body surface temperature (right and left flank averaged; one model with treatment and capture time) was affected by treatment (p = 0.006). EMMs ± SE were 36.29 ± 0.44 °C in S+W+, 36.43 ± 0.44 °C in S+W−, 38.37 ± 0.44 °C in S−W+ and 38.67 ± 0.44 °C in S−W− (lowest to highest: S+W+, S+W−, S−W+ and S−W−; Table 3). Each shaded treatment was cooler than each unshaded treatment (S+W+ vs S−W+: p = 0.019; S+W− vs S−W−: p = 0.014; S+W+ vs S−W−: p = 0.011; S+W− vs S−W+: p = 0.025), while water access made no difference within shade (S+W+ vs S+W−: p = 0.985) or without shade (S−W+ vs S−W−: p = 0.876). The factorial model confirms this: shade p = 0.001, water p = 0.484, shade × water p = 0.788.

Effect of Coat Color

Adjusted for treatment, capture time and period, coat color affected flank temperature in the mixed model (F(2, 142.2) = 6.11, p = 0.003). EMMs ± SE were 37.92 ± 0.36 °C for black, 37.42 ± 0.34 °C for red and 36.69 ± 0.41 °C for cream coats (black vs cream: p = 0.002; black vs red: p = 0.150; red vs cream: p = 0.055). The animal variance in this model was estimated as ≈ 0, so its denominator df are set by the images rather than the 16 animals. On one mean per animal (n = 16), the coat effect remained significant (F(2, 13) = 6.21, p = 0.013; black vs cream: p = 0.010; black vs red: p = 0.204; red vs cream: p = 0.096). Coat color is confounded with breed (Table 9): all 8 red animals are Braford and all black and cream animals are Jersey, so coat and breed effects cannot be separated.

# ── Model fitting with convergence / singularity handling ─────────────────────
# Fits the LMM (lmer) or, when `family` is given, the GLMM (glmer). On a
# convergence warning or singular fit, refits with bobyqa; if still singular,
# drops random terms with zero variance (never group:period) and records what
# was done in `model_log`, together with the final random-effect variances.
model_log <- tibble(model = character(), status = character(), action = character(),
                    final = character())

# `keep` lists random terms that are never dropped, even with zero variance.
fit_mm <- function(formula, data, label, family = NULL, keep = "group:period") {
  f_txt <- paste(deparse(formula, width.cutoff = 500), collapse = " ")
  ctrl_bobyqa <- if (is.null(family)) lmerControl(optimizer = "bobyqa") else glmerControl(optimizer = "bobyqa")
  fit <- function(f, ctrl = NULL) {
    msgs <- character()
    m <- withCallingHandlers(
      if (is.null(family)) {
        lmer(as.formula(f), data = data, control = ctrl %||% lmerControl())
      } else {
        glmer(as.formula(f), data = data, family = family, control = ctrl %||% glmerControl())
      },
      warning = function(w) { msgs <<- c(msgs, conditionMessage(w)); invokeRestart("muffleWarning") }
    )
    conv <- c(msgs, m@optinfo$conv$lme4$messages)
    list(m = m, conv = conv[!str_detect(conv, "singular")])
  }
  res    <- fit(f_txt)
  status <- c(if (length(res$conv)) "convergence warning", if (isSingular(res$m)) "singular")
  action <- character()
  if (length(status)) {
    res    <- fit(f_txt, ctrl_bobyqa)
    action <- "refit with bobyqa"
    if (isSingular(res$m)) {
      vc   <- as.data.frame(VarCorr(res$m))
      zero <- setdiff(vc$grp[vc$vcov < 1e-8], c("Residual", keep))
      if (length(zero)) {
        for (z in zero) f_txt <- str_remove(f_txt, fixed(paste0(" + (1 | ", z, ")")))
        res    <- fit(f_txt, ctrl_bobyqa)
        action <- c(action, paste0("dropped zero-variance term(s): ", paste(zero, collapse = ", ")))
      }
      if (isSingular(res$m)) {
        vc_k   <- as.data.frame(VarCorr(res$m))
        zero_k <- intersect(vc_k$grp[vc_k$vcov < 1e-8], keep)
        if (length(zero_k))
          action <- c(action, paste0(paste(zero_k, collapse = ", "), " variance ≈ 0 (retained by design)"))
      }
    }
    if (length(res$conv)) action <- c(action, paste("still:", paste(unique(res$conv), collapse = " / ")))
  }
  vc_final <- as.data.frame(VarCorr(res$m))
  model_log <<- bind_rows(model_log, tibble(
    model  = label,
    status = if (length(status)) paste(status, collapse = " + ") else "OK",
    action = if (length(action)) paste(action, collapse = "; ") else "—",
    final  = paste0(vc_final$grp, " = ", signif(vc_final$vcov, 3), collapse = "; ")
  ))
  res$m
}

# ── Helper: extract emmeans comparison table ──────────────────────────────────
emm_table <- function(model, factor_name) {
  emm  <- emmeans(model, as.formula(paste("~", factor_name)))
  cont <- pairs(emm, adjust = "tukey")

  emm_df <- as.data.frame(emm) %>%
    rename(Level = 1, Mean = emmean) %>%
    select(Level, Mean, SE, lower.CL, upper.CL) %>%
    mutate(across(where(is.numeric), ~ round(., 3)))

  cont_df <- as.data.frame(cont) %>%
    rename(Comparison = contrast, Estimate = estimate,
           SE_c = SE, `t / z` = t.ratio, `p-value` = p.value) %>%
    select(Comparison, Estimate, SE_c, `t / z`, `p-value`) %>%
    mutate(
      across(where(is.numeric), ~ round(., 4)),
      Sig = case_when(
        `p-value` < 0.001 ~ "***",
        `p-value` < 0.01  ~ "**",
        `p-value` < 0.05  ~ "*",
        `p-value` < 0.1   ~ ".",
        TRUE               ~ "ns"
      )
    )
  list(means = emm_df, contrasts = cont_df)
}

# 3 · Thermal Comfort Indices

## 3.1 · BGHI — Black globe-humidity index

The BGHI (Black globe-humidity index) is the primary thermal stress index for cattle in tropical conditions.
Thresholds follow Baeta & Souza (2010):
    • ≤ 74 comfort;
    • > 74–78 alert;
    • > 78–84 danger;
    • > 84 critical.

# 5 · Thermography

Thermographic images were obtained from 16 cows (4 per group: 2 Braford, 2 Jersey) at 10:00, 13:00, and 16:00h. Body temperature was calculated as (temp_mean + temp_max) / 2 following Montanholi et al. (2008). Four anatomical regions were assessed: right side (flank), left side (flank), eye, and udder. For flank analyses, the right and left flank values are **averaged per animal × day × capture time**, so each animal contributes one flank value per capture (not two).

All animal-level thermography models include `(1 | group) + (1 | group:period) + (1 | animal_id) + (1 | day)`, with period as a fixed effect. Model-based results are reported as estimated marginal means (EMM) ± SE; descriptive tables report raw mean ± SD.
